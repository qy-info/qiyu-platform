# QiYu Platform

**Shopee AI Copilot — 专为 Shopee 卖家打造的 AI 智能运营平台**

---

## 产品简介

QiYu 是一个面向 Shopee 卖家的 AI 智能运营平台。通过 AI 自动分析店铺数据、商品数据、广告数据和订单数据，帮助卖家提升运营效率和销售额。

## 核心功能

- **商品管理** — 商品上架、编辑、批量操作，多维度管理
- **智能分析** — 商品表现分析、销售趋势、利润计算
- **运营看板** — 核心指标实时监控，数据可视化
- **团队协作** — 多空间/多成员权限管理
- **自动匹配引擎** — 自动商品匹配与利润计算
- **Shopee 集成** — 官方 API 对接，商品/订单自动同步

## 适用场景

- 多店铺运营，需要统一管理
- 选品依赖人工经验，想用数据辅助决策
- 客服咨询量大，需要提升响应效率
- 运营报表靠人工整理，希望自动生成
